# temp-convert

Небольшая библиотека перевода температур между шкалами Цельсия и Фаренгейта.

## Пример

```
node example.js
```

```js
const { celsiusToFahrenheit } = require('./temp-convert.js');
celsiusToFahrenheit(100); // 212
```
