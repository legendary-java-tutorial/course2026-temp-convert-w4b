# Как участвовать в temp-convert

## Как предложить изменение

1. Откройте Issue или выберите существующий.
2. Сделайте форк и ветку от свежей `main`.
3. Внесите правку и откройте Pull Request в `main` с `Closes #<номер>` в описании.

## Как запустить проект

Нужен Node.js. Запуск примера:

```
node example.js
```

## Как сообщить об ошибке

New issue: что делали, что ожидали, что получили, версия Node.js.
